# Warframe Tracker — краткая инструкция

## 1. Задания

- **Ежедневные / Еженедельные** — переключение между списками заданий.
- **Галочка** — отметить задание выполненным.
- **✎** — редактировать задание.
- **✕** — удалить задание.
- **+ Добавить** — создать своё задание.
- **Сброс** — снять отметки выполнения.
- **JSON ↓** — сохранить задания в файл.
- **JSON ↑** — загрузить задания из файла.

<text>**ВАЖНО: сохраняйте `tasks.json` через кнопку JSON ↓!**</text>

Это резервная копия ваших заданий. При переустановке программы, Windows или переносе на другой компьютер данные могут потеряться. Храните файл в надёжном месте. Для восстановления нажмите **JSON ↑** и выберите сохранённый файл.

## 2. Live Tracking

Показывает актуальные игровые события Warframe.

- **Обновить** — получить свежие данные вручную.
- Информация обновляется автоматически при открытом разделе.

Для работы нужен интернет.

## 3. Мои сборки

Создание и хранение собственных билдов.

- **+ Создать сборку** — создать новый билд.
- Выберите предмет и установите моды в ячейки.
- **Сохранить сборку** — сохранить билд.
- **Изменить** — редактировать сохранённый билд.
- **✕** — удалить билд.

## 4. Настройки

Позволяют изменить оформление окна: размеры, шрифт, цвета.

- **Применить настройки** — сохранить изменения.
- **По умолчанию** — вернуть стандартное оформление.
- **Загрузить задания из GitHub** — обновить список заданий.
- **Проверить обновление архива** — проверить наличие новой версии программы.

**Рекомендация:** регулярно создавайте резервную копию `tasks.json`, чтобы не потерять свои задания.
