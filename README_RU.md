# Warframe Tracker — Windows x64

Настольное приложение на C# WinForms + Microsoft WebView2 (.NET 8). Окно без системной рамки; пользовательские задания, сборки и настройки хранятся локально.

## Быстрая сборка на Windows

1. Установите **.NET 8 SDK**: https://dotnet.microsoft.com/download/dotnet/8.0
2. Установите **Microsoft Edge WebView2 Runtime**: https://developer.microsoft.com/microsoft-edge/webview2/
3. Распакуйте проект.
4. Запустите `build-win-x64.bat`.
5. Готовая папка появится в `dist/WarframeTracker-win-x64/`, архив — `dist/WarframeTracker-win-x64.zip`.

Публикация выполняется как framework-dependent: .NET 8 включён в сборку. WebView2 Runtime устанавливается отдельно (обычно он уже есть на Windows 10/11 с Edge).

## Автоматическая сборка через GitHub Actions

В проект добавлен workflow `.github/workflows/build-windows.yml`.

1. Создайте свой GitHub-репозиторий и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions**.
3. Выберите **Build Warframe Tracker (Windows x64)** и нажмите **Run workflow**. Также сборка автоматически запускается при push изменений в `main` или `master`.
4. Откройте завершённый запуск workflow и скачайте artifact `WarframeTracker-win-x64`.
5. Распакуйте ZIP и запустите `WarframeTracker.exe`.

Артефакты workflow хранятся 14 дней. Чтобы получить новый архив, запустите workflow ещё раз.

## Источники данных

### Игровые данные — WFCD/warframe-items

Приложение загружает публичные JSON из `https://raw.githubusercontent.com/WFCD/warframe-items/master/data/json/`:

- `Mods.json` — модификации;
- `Warframes.json` — варфреймы;
- `Primary.json`, `Secondary.json`, `Melee.json` — основное, вторичное и ближнее оружие;
- `Arch-Gun.json`, `Arch-Melee.json`, `Archwing.json` — арч-оружие и арчвинги;
- `Pets.json`, `Sentinels.json`, `SentinelWeapons.json` — спутники и оружие стражей;
- `i18n/ru.json` — русский слой локализации.

Перевод сопоставляется по игровому `uniqueName`: запись берётся непосредственно из `ru.json` (`словарь[uniqueName]`), включая русские названия, описания и локализованные `levelStats` модов. Если перевода для конкретного элемента нет, используется оригинальное название.

### Фильтрация модификаций по типу сборки

В редакторе сборки доступны отдельные типы: варфрейм, основное оружие, вторичное оружие, ближний бой, арчвинг, арч-пушка, арч-ближний бой, спутник и оружие стража. Слоты и справочник показывают только моды, совместимые с выбранным типом по `compatName` и `type` из `Mods.json`. Модификации, рассчитанные на конкретный класс или конкретное оружие, дополнительно сверяются с выбранным предметом (например, моды для луков, глеф или Hek). Общие моды остаются доступными для всех подходящих сборок. В пользовательском справочнике при добавлении собственного мода также можно указать совместимость.

### Задания — q7vych/w-tracker

Источник заданий остаётся `https://raw.githubusercontent.com/q7vych/w-tracker/main/tasks.json`. Обновление игровых каталогов WFCD не меняет логику заданий, отметки выполнения или расписание.

## Обновления и локальное хранение

- При запуске выполняется проверка источников.
- Кнопка **«Проверить и обновить данные»** запускает её вручную.
- Игровые справочники сохраняются в локальном хранилище WebView2 и используются как резервная копия без интернета.
- Первая загрузка каталогов требует подключения к интернету.
- Пользовательские сборки, задания и настройки остаются на компьютере; приложение не отправляет их в GitHub.

## Структура проекта

- `index.html` — интерфейс приложения и редактор сборок;
- `Program.cs`, `TrackerForm.cs` — WinForms/WebView2 оболочка;
- `WarframeTracker.csproj` — проект .NET 8;
- `.github/workflows/build-windows.yml` — автоматическая сборка Windows x64.

## Ограничения

Каталог предметов и модификаций загружается из WFCD. Числовой калькулятор пока упрощённый: он не воспроизводит все игровые формулы, условия активации модов, эффекты убийств/попаданий в голову, статусы и синергии. Текущие расчёты не являются точным симулятором урона.

## Атрибуция

Игровые данные поставляются проектом [WFCD/warframe-items](https://github.com/WFCD/warframe-items). Warframe Tracker не является официальным продуктом Digital Extremes. Названия, изображения, игровые данные и переводы принадлежат соответствующим правообладателям и авторам.

### Загрузка заданий
Кнопка «Загрузить задания из GitHub» получает `tasks.json` непосредственно из:
`https://raw.githubusercontent.com/q7vych/w-tracker/main/tasks.json`

Ответ читается как текст и затем разбирается через `JSON.parse`, поэтому HTTP 200 отделён от ошибки содержимого ответа.
